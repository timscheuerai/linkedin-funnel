# Add graphics that explain the words

Scout the final cut for moments that benefit from a number, comparison, step, label or supporting image. Read `context/brand/BRAND.md`. Do not add a graphic merely to satisfy an invented retention interval.

Write a motion plan with source phrase/word cue, payload, duration, screen region and reason. Resolve cues from the final transcript; if a cue occurs twice, identify the intended occurrence. A graphic's payoff must arrive with the relevant spoken fact, not just its entrance animation.

Keep captions, face and graphics in distinct readable regions. Use lower-third panels when they preserve useful footage; full-screen scenes need a narrative reason. Every displayed metric must have a supported value and unit.

Use the available renderer's actual compositing model. Check alpha, layering, text metrics and font loading. Changes to the edit require re-resolving cues.

Inspect before/during/after frames and play the sequence with audio. Return editable motion data/project and the rendered output; report uncertain timing or unrendered elements. Use `shorts-qa` for final checks.
