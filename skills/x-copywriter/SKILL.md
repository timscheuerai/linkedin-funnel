# Write for X

Read the source, audience, cleared proof and writing samples in `context/`. Choose a single post when it can complete the idea. Use a thread only for an explanation that earns several distinct steps.

Write a specific opening the rest can substantiate. Each thread post adds information and connects to the previous one; avoid artificial cliffhangers and repeated conclusions. Keep links and attribution near the relevant claim.

Match the author's vocabulary and rhythm. Do not manufacture slang, outrage, controversy, anecdotes or screenshots to mimic platform culture. A missing voice corpus permits a neutral draft, not a claim of voice matching.

Check current account/format limits when fitting exact publication constraints, including link handling. Count text with the actual platform composer or supported tooling when available; ordinary string length is only an approximation of platform weighting.

Deliver paste-ready copy, ordered thread numbering when helpful, and source notes outside the copy. Preview media with `graphics-designer` if requested. Drafting does not publish or start reply automation.
