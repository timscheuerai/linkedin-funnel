# Script a useful video

Read the audience, source material, actual product/workflow and author voice. State what the viewer should know or be able to do at the end. Confirm whether the deliverable is a read-aloud script, presenter outline or demo shot list.

Outline: opening promise, enough context to follow, ordered demonstration/explanation, limitations, result and relevant next action. Each beat needs spoken copy, visual/demo action and supporting source. Put setup friction and prerequisites before the step that needs them.

Use spoken sentences and concrete transitions. Show the actual output when it exists. Label proposed screens and placeholders; do not describe a non-working feature as already demonstrated. Keep scripts proportionate to the requested runtime and verify timing with a read-through.

Deliver the script plus shot list and missing assets. Use `youtube-description` after a transcript or stable final cut exists, and `youtube-thumbnail` for a thumbnail whose promise matches the video. A script is not a rendered or published video.
